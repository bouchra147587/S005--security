How the Model Works

Preprocessing
Raw emails cleaned, missing values handled, dates parsed, text normalized to lowercase ASCII.
Feature Engineering
19 behavioral signals: URL patterns, keyword hits, sender domain, structure, timing data.
TF-IDF Vectors
Subject and body converted to 18,000 text features using trained bigram TF-IDF vectorizers.
Classification
Voting Ensemble (LR + Random Forest + XGBoost) across 18,018 combined features returns phishing probability and verdict.
// Detection Capabilities

What We Analyze

URL Pattern Analysis
IP-based URLs, dangerous TLDs (.xyz, .ru, .tk), obfuscated links, URL length anomalies and domain mismatches.
Urgency Language
40+ phishing keyword triggers detected: "urgent", "verify account", "action required", "prize", "suspended".
Sender Intelligence
Domain extraction, free provider detection (Gmail, Yahoo), sender/recipient domain alignment checks.
Structural Profiling
Body/subject length, exclamation density, question marks — phishing emails have distinct structural fingerprints.
TF-IDF Text Model
15,000-feature body + 3,000-feature subject bigram model trained on 31K emails with sublinear TF scaling.
HTML Detection
Rich HTML embedding is a common phishing vector, detected and weighted in the final classification score.
