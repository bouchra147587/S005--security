# S005 — Phishing Email Detector using Machine Learning

##  Overview

This project focuses on building a **machine learning-based system** to detect phishing emails. The system analyzes email content, extracts relevant features (such as suspicious keywords and malicious links), and classifies emails as **phishing** or **legitimate**.

---

##  Objectives

* Develop a machine learning model for email classification
* Identify patterns commonly found in phishing emails
* Extract meaningful features from email content
* Improve detection accuracy while minimizing false positives
